# Interesting AI Agent Skills

用于收集和维护有趣、可复用的 AI agent skills 与 prompt 模板。

## 目录结构

- `prompts/`: 可直接复用的 prompt 模板。

## 当前内容

- [论文阅读专家 Prompt](./prompts/paper-reading-expert.md): 用于围绕论文原文、相关工作和领域视野生成分级可靠性分析。

## 维护原则

- 每个 prompt 或 skill 独立成文，便于版本管理和复用。
- 尽量保留原始意图，同时用清晰标题和层级增强可读性。
- 涉及外部资料时，明确标注信息可靠性级别。
